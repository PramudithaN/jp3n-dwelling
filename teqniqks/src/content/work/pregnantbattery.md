## Structural Overview
pregnantbattery is a lean browser diagnostic utility that observes charging states, discharge rates, and hardware battery health directly through client-side Web APIs.

## Engineering Intent
Strips away analytics beacons and heavy UI frameworks to deliver immediate, zero-telemetry battery diagnostics on any device.
- Strict client-side TypeScript execution with zero server calls.
- Real-time charging and discharge telemetry readout.
- Clean static HTML & CSS delivery.

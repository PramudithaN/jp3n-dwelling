## Structural Overview
A straightforward careers portal engineered for technical candidates to browse open engineering roles and apply without heavy frontend framework overhead.

## Engineering Intent
Built with direct HTML templates and lightweight Python backend/scripting support so job listings load fast and stay maintainable.
- Direct semantic HTML structure for listings.
- Python-backed tooling and clean static assets.
- Zero third-party ad trackers.

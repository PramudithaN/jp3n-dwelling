How to Contribute

WE
REVIEW
EVERY PR.

PR

01. Fork & Clone

Fork any of our open repositories on GitHub and clone it locally to explore the codebase.

02. Pick an Issue

Browse open issues labeled good first issue or open a focused RFC before large refactors.

03. Branch Cleanly

Create a descriptive branch (feat/... or fix/...) from main with small, atomic commits.

04. Build & Verify

Keep dependencies minimal, follow the existing style, and verify builds/tests pass locally.

05. Open a Pull Request

Link the issue in your PR description, explain the intent clearly, and keep diffs focused.

06. 48h Core Review

A Teqniqks maintainer reviews every PR within 48 hours with constructive, zero-gatekeeping feedback.

### How to Contribute

Theme Changer is built with pure web standards. We are looking for contributors interested in color science, CSS tokens, and zero-runtime architecture.

1. Fork the repo and clone locally.
2. Check the issue tracker for the `good-first-issue` tag.
3. Submit clean, single-responsibility pull requests.

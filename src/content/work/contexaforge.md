## Structural Overview

ContexaForge scans local project repositories to automatically synthesize structured context files, coding rules, and reusable agent workflows.

## Engineering Intent

Designed to bridge raw source trees and AI coding agents with repeatable, deterministic CLI commands rather than manual prompt copying.

- Automated repository structure and stack analysis.
- Generates tailored context, rules, and workflow definitions.
- Pure JavaScript CLI built for local developer velocity.

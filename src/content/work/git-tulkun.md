## Structural Overview

git-tulkun transforms a developer's GitHub contribution graph and primary language palette into a procedural pixel-art Tulkun whale looping GIF for profile READMEs.

## Engineering Intent

Combines a high-speed Rust procedural renderer with Python tooling and GitHub Actions automation to generate crisp, deterministic pixel art from real contribution data.

- Reads live GitHub contribution history and language colors.
- Renders looping pixel-art GIFs in Rust with zero external runtime bloat.
- Automated via GitHub Actions with a live web configurator.

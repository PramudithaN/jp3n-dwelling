## Structural Overview
An interactive WebGL globe built with Three.js, allowing smooth orbital inspection of a 3D Earth model directly in any modern browser.

## Engineering Intent
Demonstrates GPU-accelerated 3D rendering in pure client-side JavaScript and HTML with zero server-side rendering dependencies.
- Real-time Three.js WebGL scene and camera controls.
- Hosted statically on GitHub Pages for instant access.
- Clean JavaScript and HTML architecture.
